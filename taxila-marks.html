Taxila Marks

Shows your marks, upcoming deadlines and submission status for every Taxila course in one overlay. It runs only on a Taxila page while you're logged in.

It reads your own Taxila pages in your browser and sends nothing anywhere else. Each click loads the latest version of the code from GitHub, so you get fixes without reinstalling. It doesn't change anything on Taxila or submit anything.

Install

Drag this button onto your bookmarks bar (press Ctrl+Shift+B, or Cmd+Shift+B on a Mac, if the bar is hidden):

📊 Taxila Marks

Or paste it into a bookmark

Copy the code, then edit any bookmark and paste it into the URL field.

Use

  1. Log in to Taxila and open any page there.
  2. Click the bookmark. Close the panel with the ✕ in the top-right corner. Links open in a new tab, so the panel stays open.
